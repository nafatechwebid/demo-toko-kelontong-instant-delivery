Masuk / buat toko baru

Kalau slug belum ada, toko baru otomatis dibuat dengan PIN ini. Kalau sudah ada, PIN harus cocok.

01

Nama toko & logo

Ditampilkan di bagian atas halaman toko.

02

Daftar barang 0/100

Maksimal 100 barang. Tambah satu per satu.

03

Rekening bank 0/10

Maksimal 10 rekening untuk pembeli transfer manual.

04

QRIS statis

Upload gambar QRIS statis toko. Field di bawah bebas diisi — bisa link referral (mis. link daftar QRIS di penyedia tertentu) atau catatan untuk pembeli.

05

Lokasi & radius antar

Cara isi: buka halaman ini dari HP saat Anda benar-benar berada di dalam toko, lalu tekan "Ambil lokasi saat ini". Atur radius agar pembeli tahu apakah alamatnya masih terjangkau kurir instant.

06

Ongkir instant

GoSend, Grab Express, SPX Instant, dan Maxim tidak punya API terbuka untuk reseller kecil, jadi ongkir dihubungkan lewat aggregator (Biteship/KiriminAja) yang sudah resmi terkoneksi ke kurir-kurir tersebut. Daftarkan toko di aggregator pilihan, lalu isi API key di file config.js sebelum upload ke GitHub Pages — tidak perlu diisi dari halaman ini.
